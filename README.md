# Hi
I'm a Computer Engineering student at UERJ - IPRJ, focusing on the study of Computer Vision techniques with Video Processing. I particularly enjoy working on low-level programming, computer architecture and math.

**Currently working on:** [VideoReconstruction](https://github.com/bernardobrust/VideoReconstruction), a tool for analyzing AV1 video compression data and it's applications on Computer Vision, which I plan to later scale as a 3D reconstruction system for video.
